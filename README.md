# Car-HUD
Car-HUD application repository V1.4
The app will display a flight simulator type Heads Up Display using your phone's sensor data
Optional OpenMap display of current location will be displayed (will take up additional data)
iPhone and Android versions avaialble.

A demo video is available here https://youtube.com/shorts/FlD-W0D5ztg
Red lines will show peaks of Speed, Height, Pitch and Side Force
Blue lines will show maximum negative pitch and lowest height
